Access Mods

Screen reader mods that make games speak. Free, and built because nobody else was going to.

Injustice 2 Mortal Kombat 11 Help & Reporting

What these are

Big fighting games draw their menus as pictures. A screen reader sees nothing, which means a blind player cannot pick a character, set up a match, or get through a story chapter without sighted help. These mods hook into the game's own interface code and read the real text aloud, so the menus finally talk.

They speak through NVDA or JAWS when one is running, and fall back to the Windows voice when neither is. They are menu readers: they do not play the game for you, and they do not narrate the fight itself.

Both mods load code into the game the same way modding frameworks do, so an antivirus may take an interest. Nothing is changed in the game's own files. They read text and nothing else, and both have been used online, ranked included, without trouble.

Injustice 2 Accessibility, update only

Windows · Steam · Two mod files, upgrade only

For people who already have the mod installed and working. Close the game, then copy Injustice2.Accessibility.dll and Injustice2.Accessibility.deps.json into Binaries\Retail\Reloaded-II\Mods\Injustice2.Accessibility inside your game folder, replacing what is there. If an old Injustice2.Accessibility.pdb is sitting in that folder, delete it; it is a leftover debug file and is not needed. Keep a copy of the old files first if you want a way back. Nothing else changes, and you do not need to run the installer again.

Download the update (.zip, 46 KB)

What you need

  • Injustice 2 installed through Steam. The mod does not include the game.
  • The Microsoft .NET 9 Desktop Runtime, 64 bit. Pick the entry called ".NET Desktop Runtime 9.x, Windows x64 Installer". If the game starts but never says "Injustice 2 accessibility loaded", this is almost always the missing piece.
  • A screen reader running before you launch the game. NVDA, JAWS and Narrator all work, with SAPI as a fallback. Nothing needs configuring for speech; the mod finds your reader on its own.

Installing the full package

  1. Unzip the package somewhere convenient, like your desktop.
  2. Open the folder named Retail inside it, select everything in that folder, and copy it.
  3. Go to your Injustice 2 install folder, then into Binaries, then Retail. The usual path is C:\Program Files (x86)\Steam\steamapps\common\Injustice2\Binaries\Retail. If you are not sure where the game is, in Steam open Injustice 2, then Properties, then Installed Files, then Browse.
  4. Paste everything there, saying yes to replacing files if Windows asks. You are only adding mod files; no game files are overwritten.
  5. In that same Retail folder, right click Injustice2_Installer.exe and choose "Run as administrator". Approve the Windows prompt. It will say "Mod installed successfully."
  6. Launch Injustice 2 normally from Steam. Within a few seconds of the window appearing you should hear "Injustice 2 accessibility loaded".

Step 5 is required. It writes one Windows registry entry so the game starts through the mod launcher, which is what keeps Steam, achievements and online play working normally.

Uninstalling

Open a command prompt in the Binaries\Retail folder and run Injustice2_Installer.exe /uninstall as administrator. It will say "Mod uninstalled. The game will now launch without the mod." The game then starts normally, and you can delete the mod files afterwards if you want them gone.

What is new in this build

  • Move lists now carry the frame data. On a move you hear the name and position, a short note on what the move does, and then the numbers: move type, start up, active, recover, damage, block damage, block advantage, hit advantage and cancel. Columns the game leaves empty are skipped rather than read as "not applicable". Moves marked as ability moves, or as affected by strength or by an ability, say so. Section headings read their own name instead of repeating the move you were last on, and tagging a move with the Y button announces the new count, for example "tagged, 1 of 10".
  • Diagnostic logging is off unless you ask for it. Earlier builds wrote a detailed log the whole time you played, which grew to megabytes on a machine that was not chasing a bug. Press F10 when you want it.

Also in recent builds

  • Customization no longer bleeds text from screens you have already left.
  • Gear numbers say which number is which, for example "loadout total strength 1200" against "this piece strength 40", and a change like plus 14 reads as "14 higher than equipped".
  • Gear unlocked after a match is announced as it is revealed, rather than only after you press a button.
  • The dyes and shaders screen, previously silent, reads name, price and unlock message.
  • Mother box and loot drops say which character a piece of gear is for.
  • Another player's online profile and hero card read.
  • Several announcements that used to speak once per session and then go quiet now repeat properly.

Keys

All of these work only while the game window is in the foreground.

  • F1: read the whole current screen. This is the catch-all. If a screen says nothing on its own, press F1.
  • F4: read details for whatever you are on. In a tutorial lesson it re-reads the full lesson text; on a piece of gear it reads the complete gear card with slot, character, stats, set bonus and ability; anywhere else it falls back to the whole screen.
  • F6: take a screenshot into the mod folder, for reporting problems.
  • F7: repeat the control hints for this screen.
  • F8: repeat the last story mode branching choice.
  • F9: repeat the last thing spoken, in full.
  • F10: turn diagnostic logging on or off. It is off unless you switch it on.
  • Right stick click: repeats the last line, same as F9. In a tutorial lesson it re-reads the lesson instead.

F4 is the read-details key in this build. Older builds used F2, which was freed up so the separate I2Hook cheat panel can use it.

Known rough edges

  • The direction announced during story mode quick time events can be wrong.
  • The character tutorial list, where you pick which tutorial to run, does not read well yet.
  • Guild screens other than the join page, the sell popup for individual items, and some detail panels are not covered.

About logging

The mod keeps one small file, AccessKit.log, which records whether it loaded and what it hooked. That one is always written and stays small. The detailed diagnostic logs are off: they only start when you press F10, and they stop again on a second press or when you close the game. If you are coming from an older build, the mod folder probably holds a large AccessKit_dump.log from back when logging ran all the time. Any file in that folder whose name starts with AccessKit_ is safe to delete while the game is closed.

Credits

The original Injustice 2 accessibility mod, the launcher and the installer are by Amethyst. This build extends that work with a lot of additional screen coverage. The loader underneath is Reloaded II by Sewer56, and speech goes through the prism library.

Mortal Kombat 11

Version 0.5.0, 26 August 2026. Steam version on Windows.

MK11 Accessibility 0.5.0

Windows · Steam · Installer included

Mortal Kombat 11 has no screen reader support at all. This mod hooks the game's interface code and speaks the real text it is drawing, and it knows which item you are actually sitting on rather than guessing from the screen. This build adds audio navigation for the Krypt, and it is a large step up from 0.2.0, which is what used to be on this page.

Download MK11 Accessibility 0.5.0 (.zip, 3.3 MB)

What you need

  • Mortal Kombat 11 on Windows, the Steam version.
  • The Microsoft .NET 9 Desktop Runtime, 64 bit. Pick the entry called ".NET Desktop Runtime 9.x, Windows x64 Installer". This is the one thing most people will not already have, and if the mod stays silent this is almost certainly why.
  • NVDA or JAWS, if you want it to speak through your usual voice. Optional; without one it uses the Windows voice.

You do not need administrator rights, and you do not need to change any Windows settings.

Installing

  1. Unzip the folder anywhere you like. Your downloads folder is fine. Do not unzip it into the game folder.
  2. Run Install.bat.
  3. It will try to find Mortal Kombat 11 on its own, including on other drives. If it cannot, it will ask for the full path to your Mortal Kombat 11 folder, meaning the folder containing a folder called Binaries.
  4. It will tell you when it is done. Close the game first if it is running; the installer will stop and say so if it is.

Upgrading from an earlier version is the same process. Run Install.bat again and it will replace what is already there.

Start the game with MK11.exe, not MK11_DX12.exe. That is a different build of the game and the mod will refuse to attach rather than risk breaking anything. If it worked you will hear "Mortal Kombat 11 accessibility loaded" a few seconds after the window appears.

What is new in 0.5.0: finding your way around the Krypt

The Krypt is not a menu. It is a three dimensional world you walk around in, so none of the menu reading applies to it, and until now there was nothing there at all. You could hear a chest once you were standing on it, but there was no way to find one. There is now a beacon that points you at the objects around you using sound.

It works like a map that always faces north, rather than like something strapped to your character. That matters, because the camera swings around as you walk, and every version that was tied to the camera became unreadable the moment you turned. Three things carry the information:

  • Which ear the sound is in tells you which side the object is on. Full left is due west of you, full right is due east.
  • Pitch tells you whether it is above you or below you. Higher is above.
  • How often the sound repeats tells you the distance. Far away it ticks about once every two seconds, and it speeds up as you close in until it is nearly continuous when you arrive. This is the part to steer by: walk, and if the ticking speeds up you are going the right way. If it slows down, turn around.

North and south are not carried by the sound, because the left and right channels and the pitch are both already spoken for. Instead the mod speaks the compass bearing when the target changes. Both the speech and the sound use compass directions, so they can never contradict each other.

When you reach something it says "reached it, next" and moves on to the next nearest object, so it does not keep pinging at a chest you have already opened. Not everything it points at is a chest: the mod can see the objects the game has placed in the world but cannot yet tell chests from doors from scenery, and a few of them cannot be reached at all. Press F8 to skip one and move to the next.

Also fixed in this build: the Krypt used to read its coordinate display aloud twelve times a second, so you heard something like "10594, 39" endlessly over the top of everything else. That is gone.

Please treat the beacon as experimental. It has found real chests, which is more than any earlier version managed, but the tuning is a first attempt and feedback on it is genuinely useful.

Also new since 0.2.0

  • Towers of Time works. Each portal reads the tower name, what kind of tower it is, its difficulty out of five, which portal you are on, how long before it rotates away, and what it pays out. Before this a portal said only its name, and MK11 names its towers as jokes like "help" and "pit fighter", so telling them apart was impossible. Pressing Y opens the Race Against Time board, which used to be completely silent.
  • Tower details read. Choosing a tower opened a panel that said nothing at all. It now reads the name, the number of opponents, the difficulty, the modifiers, and the tower's own description, which is where the game hides restrictions like tag assist konsumables not being allowed. It also reads rewards, your high score and your rank, and if the tower is locked it says which tower you have to finish first.
  • Towers that demand a particular fighter. Some towers only let you play as one character, and the game shows this by greying out every other portrait, which is invisible to us. The panel now names the required fighter, and moving onto a portrait you cannot pick says "locked" and repeats the game's own wording, for example "Jade required".
  • The konsumable trap is explained. The game has two konsumable screens that look identical. The one on the right trigger is a viewer and nothing can be selected on it; the one where you actually equip konsumables is opened with the X button on the screen just before a match starts. The mod used to say "available" on the viewer, which made it sound like you could add the item. It now says "view only", names the screen you are on, and reads the X button prompt on the screen that does work.
  • The screen before a match reads properly: you against your opponent, each modifier and what it does, how many konsumables you have equipped, and the button that opens the konsumable screen.
  • End of a match is read: who won, whether it ended in a fatality or a brutality, and what you were paid in koins, souls and hearts. Tower reward cards at the end of a run are read too.
  • The move list carries frame data, what each move actually does, and the move properties. Tagging a move with Y says so.
  • Abilities in kustomize read properly: whether an ability is equipped, what it costs, how many of your three slots are used, what it conflicts with, and what it does. Swapping one says what replaced what.
  • Character select reads the whole variation summary as you move the carousel, including the abilities with their inputs and the AI ratings. You do not have to press Y for it. It also speaks immediately now rather than after a short delay, choosing player two no longer reads back player one's fighter, and random select stays quiet while it spins instead of shouting a name on every hop.
  • Button names match what you are actually holding. On the keyboard it says the key; on a pad it says the button in that pad's own language, Xbox or PlayStation. It follows you if you swap mid session.

Keys

These work only while the game window is in the foreground.

  • F11: turn the Krypt beacon on and off. It starts off.
  • F8: skip whatever the beacon is currently pointing at and move to the next one. Hold control and press F8 to forget everything you have skipped or reached and start over.
  • F9: write a snapshot of everything on screen to a text file next to the log. If a screen says nothing, pressing F9 while you are on it and sending that file is the single most useful thing you can do.

What it reads today

  • Main menus and option screens, including slider values as numbers while you drag them.
  • Story mode, including chapter select and the "choose your fighter" moments, telling you which fighter is on the left, which is on the right, and which way to push.
  • Character select, stage select, and the start of a match, so you know who is fighting.
  • The tutorial: objectives when a lesson starts, and when you have completed one.
  • Kustomize: gear, kosmetics, abilities and AI behaviour. Gear and kosmetic items say whether they are locked and where they come from.
  • Towers of Time: the portal map, the towers themselves, the konsumable screens, and the reward cards at the end of a run.
  • The move list, with frame data, move descriptions and move properties.
  • The end of a match: who won, how it ended, and what you earned.
  • The Krypt: chests and rewards when you reach them, plus the beacon described above to help you find them.

What does not work yet

  • Walls in the Krypt. The beacon points you at objects, but nothing yet tells you that you are about to walk into a wall, or which way a corridor runs, so you will still get stuck on scenery. This is the next thing being built.
  • Knowing what a Krypt object is before you get to it. The beacon says "object", because the game does not label them in any way the mod can read yet.
  • Anything during an actual fight. You will not be told what your opponent is doing.
  • Online menus are covered less thoroughly than the rest. Playing online works, but expect the odd screen that says nothing.

Uninstalling

Run Uninstall.bat. By hand, delete Binaries\Retail\dinput8.dll from your game folder. That is the only file the game ever loads, and deleting it fully disables the mod. The Reloaded-II folder left behind does nothing on its own and can be deleted too. The mod does not change any of the game's own files, so there is nothing to repair or verify afterwards.

Help & Reporting

Screens that say nothing are the useful bug reports, because they are the ones nobody has found yet.

Injustice 2 logs

The mod writes its logs into its own folder, Binaries\Retail\Reloaded-II\Mods\Injustice2.Accessibility. Detailed logging is off by default; press F10 as soon as the game loads, go and do the thing that reads wrong, then send the files there whose names start with AccessKit_. If a file named AccessKit.log appears there, the mod loaded and any problem is with speech; if it does not, the mod never started, which usually means the .NET 9 Desktop Runtime is missing or the installer was not run as administrator. Some overlays can interfere too, so if nothing at all happens, try turning off the Steam overlay and any GPU recording overlays for Injustice 2. If the game stops speaking after an update, put back the files you set aside and you are exactly where you were before.

Mortal Kombat 11 logs

There is a log inside your game folder at Reloaded-II\Mods\MK11.Accessibility\MK11AccessKit.log. It is plain text, and it records whether the mod attached and what it hooked. If the mod is silent, the first few lines usually say why. A second log next to it in Binaries\Retail, MK11AccessKit_loader.log, covers the earlier startup stage.

Detailed logging is off unless you switch it on, so the mod will not quietly fill your drive with a log nobody asked for. To report a problem properly, create an empty text file called debug.txt in the same folder as the first log, then play again. That turns on a detailed recording of every piece of text the game drew and everything the mod said, into MK11AccessKit_dump.log. Send that file along with a description of what you were doing, and leave debug.txt off the rest of the time, because the detailed log grows to several megabytes and never trims itself.
